### 🚀 Featured Projects

#### 🔐 Phishing URL Detection System
An end-to-end machine learning pipeline for detecting phishing URLs, built on a dataset of **109,614 labeled URLs** with **30 structural and lexical features**.

- Performed feature engineering and compared multiple classification models
- Best model (Gradient Boosting) achieved **96.38% F1-score** and **0.9934 AUC-ROC**
- Deployed via a **FastAPI** REST API with a **Streamlit** web interface
- Supports real-time and batch prediction with model serialization for inference

🔗 [Repository](https://github.com/LyHenglong/phishing-detector)

#### ✍️ Interactive Handwritten Character Recognition System
A CNN-based computer vision project for recognizing handwritten characters in real time.

- Built and trained a Convolutional Neural Network using TensorFlow/PyTorch
- Applied image preprocessing, normalization, and data augmentation
- Achieved **96%+ test accuracy**
- Built an interactive interface for real-time character prediction
- Showcased at **Cambodia Tech Summit 2026**

🔗 [Repository](https://github.com/LyHenglong/Handwritting-Recognition-v1)
