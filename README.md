## 🚀 Featured Projects

### 📊 Telecom Customer Intelligence Platform
**[github.com/LyHenglong/Customer-Intelligence-Platform](https://github.com/LyHenglong/Customer-Intelligence-Platform)**

**What I built:** An end-to-end data and machine-learning platform for telecom customer analytics, built as a production-style pipeline rather than a single notebook. It covers churn prediction and customer segmentation, exploratory data analysis, and per-customer explainable predictions via SHAP. Data flows through a PostgreSQL + dbt transformation layer into a customer data mart, with predictions served through a FastAPI model API behind an analytics dashboard.

**Tech stack:** `Python` `Scikit-learn` `PostgreSQL` `dbt` `FastAPI` `SHAP` `Docker`

---

### 📈 XAU Sentinel
**Private repository — decision-support only, no trade execution.**

**What I built:** A read-only XAUUSD (gold) market-intelligence and decision-support platform. It analyzes market data and surfaces findings for a human to review — it does not place trades, send orders, or trade autonomously. It ingests MT5 market data across H4 / H1 / M15 / M5 timeframes, detects market structure, liquidity, and key supply/demand areas, and runs volatility/volume analysis, strategy evaluation, statistical research, and backtesting. Findings are risk-monitored, explained with AI assistance, and delivered via Telegram alerts, backed by a FastAPI service, PostgreSQL storage, and a Next.js dashboard.

**Tech stack:** `Python` `FastAPI` `PostgreSQL` `Next.js` `Docker` `MetaTrader 5`

---

### ✍️ CNN Handwritten Character Recognition
**[github.com/LyHenglong/Handwriting-Recognition](https://github.com/LyHenglong/Handwriting-Recognition)**

**What I built:** A custom ResNet-style CNN trained on the EMNIST ByClass dataset (62 classes) for handwritten character recognition — 2.77M parameters, trained on GPU, reaching 84.74% test accuracy.

**Tech stack:** `Python` `PyTorch` `CNN` `Computer Vision`

---

### 🔐 Phishing URL Detector
**[github.com/LyHenglong/phishing-detector](https://github.com/LyHenglong/phishing-detector)**

**What I built:** A machine-learning pipeline that classifies URLs as phishing or legitimate using structural and lexical feature engineering, served through a FastAPI backend with a Streamlit interface for single and batch predictions.
